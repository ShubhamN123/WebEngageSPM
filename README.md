# WebEngage SPM

This repository contains separate Swift Package Manager packages for WebEngage libraries.

## Installation

Add only the specific library you need:

### WebEngage Core
```
https://github.com/YOUR_USERNAME/SPM-Core
Branch: beta-test
Path: WebEngage
```

### WELocation
```
https://github.com/YOUR_USERNAME/SPM-Core
Branch: beta-test
Path: WELocation
```

### WENotificationInbox
```
https://github.com/YOUR_USERNAME/SPM-Core
Branch: beta-test
Path: WENotificationInbox
```

### WEPersonalization
```
https://github.com/YOUR_USERNAME/SPM-Core
Branch: beta-test
Path: WEPersonalization
```

Each package is independent and will only download its specific framework.
